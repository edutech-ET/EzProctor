Quick Help

Before You Start

1. Create the exam

Set the title, test type, language, and duration. This becomes the template for all sessions.

2. Create a session

Sessions are the actual sitting windows. Students join these and the timer comes from the exam template.

3. Register students

Assign each student to the right session so the dashboard can track them properly.

4. Start and monitor

Open the session, let students verify and launch the app, then watch progress and integrity signals live.

5. Review submissions

Use the Submissions area to inspect files or download the complete hand-in package.

Launch Flow

What Students Do

Share the verification page with students, then have them follow these exact steps.

  1. Open the verification page in a browser.
  2. Click Verify and Launch App.
  3. The desktop lockdown app opens and takes the student into the IDE.
  4. The timer begins and activity is streamed back to this dashboard.
  5. The student clicks Submit and Exit when finished, or the teacher stops the session.
